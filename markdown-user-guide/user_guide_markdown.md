## 2. Getting started   

### 2.1 Sign in to TaskFlow   

To sign in to TaskFlow:  
1. Open your web browser.   
2. Go to the TaskFlow login page.   
3. Enter your email address.  
4. Enter your password.   
5. Click **Sign In**.   
   
>**Tip**: Select Remember me if you are using TaskFlow on a trusted device.   

#### 2.1.1 Reset your password   

If you forgot your password:  
1. On the Sign In page, click **Forgot password?**   
2. Enter your registered email address.   
3. Click **Submit**.   
4. Check your email for the password-reset link.   
5. Follow the instructions in the email to create a new password.   

### 2.2 TaskFlow dashboard   

After you sign in, the Dashboard appears.   
The dashboard contains the following sections:     
- **My Tasks** – Displays tasks assigned to you.   
- **Projects** – Displays the projects you can access.   
- **Notifications** – Displays recent activity.   
- **Calendar** – Displays upcoming deadlines.   
- **Reports** – Displays project-related reports.   

### Dashboard component

## 3. Create a project   

Follow these steps to create a project:    
1. From the dashboard, select **Projects**.   
2. Click **Create Project**.   
3. Enter a name in the **Project Name** field.   
4. Enter a description.   
5. Select the project start date.   
6. Select the project end date.   
7. Click **Create**.   

The new project appears on the Projects page.   
> **Important**: The project name must be unique within your organization.   

### 3.1.1 Project information   

A project can contain the following information:   
- Project name  
- Description     
- Start date     
- End date     
- Project owner     
- Team members   
- Project status    

## 4. Create and manage tasks   

Tasks are individual activities that must be completed as part of a project.     

### 4.1 Create a task   

To create a task:    
1. Open a project.   
2. Click **Add Task**.   
3. Enter a task title.   
4. Enter a description.   
5. Select a priority.   
6. Assign the task to a team member.   
7. Specify a due date.   
8. Click **Save**.   

#### Example   

**Task**: Create user guide   
**Priority**: High   
**Assignee**: Documentation Team   
**Due date**: September 30, 2026   

### 4.2 Set task priority   

TaskFlow provides three priority levels:   
- Low   
- Medium   
- High   

Use the following guidelines when selecting a priority:  
| Priority | When to use |     
| --------- | --------- |   
| Low | The task is useful but does not require immediate attention. |   
| Medium | The task should be completed within the planned schedule. |   
| High | The task is critical and requires immediate attention. |   

> **Tip**: Use priority levels consistently across your project so that team members can easily identify urgent work.   

## 5. Add comments   

You can use comments to communicate with other project members.   
### 5.1 Add a comment   

1. Open the task.   
2. Scroll to the Comments section.   
3. Enter your message.   
4. Click **Post**.   

For example:  
> The first draft of the user guide is ready for review. Please add your comments by Friday.   

#### 5.1.1 Mention a team member

To notify a specific team member:     
1. Type `@`.   
2. Enter the person's name.   
3. Select the person from the list.   
4. Enter your message.   
5. Click **Post**.   

The selected user receives a notification.

## 7. Track task progress   

TaskFlow uses statuses to indicate the current state of a task.   
| Status | Description |   
| ------ | ------|   
| Not Started | Work has not started.|   
| In Progress | Work is currently underway. |   
| Under Review | Work has been completed and is awaiting review. |   
| Completed | The task has been completed. |   
| Blocked | Work cannot continue because of an issue or dependency. |   

## 7.1 Change the task status   

To change the status of a task:   
1. Open the task.   
2. Click the **Status** drop-down list.     
3. Select the required status.   
4. Click **Save**.

## 10. Troubleshooting   

If you encounter an issue while using TaskFlow, try the following solutions.   

### 10.1 Unable to sign in   
**Problem**: You cannot sign in to TaskFlow.   

**Possible causes**:  

- Incorrect email address   
- Incorrect password   
- Account is locked     
- Network connectivity issue   

**Solution**:   

1. Verify that your email address is correct.   
2. Check that Caps Lock is disabled.   
3. Reset your password if necessary.     
4. Check your internet connection.     
5. Contact your administrator if the issue persists.   

## 10.2 File upload fails   

**Problem**: You receive an error when uploading a file.   

**Possible causes**:   

- File exceeds the maximum size.   
- File type is not supported.     
- Internet connection was interrupted.   
  
> **Important**: Do not repeatedly upload the same file if the application displays a server error. Contact your administrator if the problem continues.

## 13. Best practices   

Follow these recommendations when using TaskFlow:   
- Use clear and descriptive task titles.   
- Assign each task to a specific person.     
- Set realistic due dates.     
- Keep task descriptions concise.    
- Update task statuses regularly.     
- Use comments for project-related communication.     
- Attach relevant supporting documents.     
- Review overdue tasks regularly.   
> **Best Practice**: Keep task information up to date so that everyone working on the project has the same understanding of the current status.
